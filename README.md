# c-programming
My C programs from B.Tech 1st year

- attendance.c: Calculates attendance % and how many classes you can miss to stay above 75%.
- marks.c: Calculates total, percentage, grade, highest and lowest marks.
- calculator.c: Simple calculator using switch-case.
- expense.c: Tracks daily expenses and remaining budget.
- study_planner.c: Splits daily study hours across subjects based on exam date and difficulty.
